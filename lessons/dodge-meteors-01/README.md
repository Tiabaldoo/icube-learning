# Увернись от метеоритов

Игра 1★, ID `dodge-meteors-01`. Основной эталон пользователя хранится в `reference.ts`, объединённый пример — в `reference-all.ts`. Рисунок в `img` сохранён: все 256 пикселей совпадают с готовым ресурсом галереи `sprites.projectile.drop3`. Корабль — `sprites.space.spaceRedShip`.

Основной урок: Блоки — 22 шага, JavaScript и Python — по 21. Имена Python: `ship` и `meteor`; `player` конфликтует со встроенным модулем MakeCode. Все значения, события и поведение совпадают с эталоном.

Три независимых улучшения начинаются с основной игры: `meteors-music` (5 шагов), `meteors-lives` (7), `meteors-speed` (4) в каждом режиме. Пауза и Ghost сохранены без дополнительных таймеров и переменных.

Авторские данные и программные состояния: `scripts/meteor-course.mjs`, `generate-meteor-course.mjs`. Подлинные снимки получены через `capture-meteor-course.mjs` с существующим MakeCode capture. `verify-meteor-code.mjs` проверяет четыре новых финальных варианта настоящими компиляторами TypeScript и MakeCode Python, а также отсутствие серых блоков. Эти скрипты не тестируют интерфейс платформы и не публикуют проекты MakeCode.

Карточка использует существующую систему обложек (корабль и метеориты), без изменения React, CSS и установщика.
