# Python

Самостоятельный урок той же игры: 18 шагов и 5 вопросов.
Переменные: player, star; пользовательский тип: Star.

Финальный образец получен из реального преобразования MakeCode:
та же программа открыта в Blocks, затем в Python. Сохранены порядок
функции и подключения события, объявление star: Sprite = None,
snake_case-команды и формат img с тройными двойными кавычками.
Автоматический суффикс player2 нормализован до запрошенного имени player.

Матрицы рисунков во viewer — результат редактора изображений;
ученик их не набирает. Галерея использует существующие UI-assets.
Новые снимки — только две палитры Python:

```bash
node scripts/capture-python.mjs
```

Скрипт переиспользует существующий capture helper, выводит исходный
MakeCode Python и создаёт эти два снимка. Он не проверяет UI приложения.
Улучшения Python пока не поддерживаются; прогресс не сохраняется.
