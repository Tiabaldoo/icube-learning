# Лабиринт: продолжение (`maze-02`)

Урок дополняет сохранённый `maze-01`. Начальные образцы совпадают с окончанием первого урока. Финальные образцы, карты, рисунки, механики и улучшение `maze-chase` сохранены без изменений.

## Последовательность

Блоки: 60 шагов. JavaScript: 57. MakeCode Python: 58.

Переменные, выбор карт, пустые основы функций, их команды и события вводятся постепенно. Ключ сначала пустой, рисунок появляется в шаге рисования. Начальное «ЕстьКлюч = ложь» сохраняется: сброс внутри функции добавляется отдельно. UI-подсказки показывают меню и результат внутри одного действия. Маркеры имеют снимок нужной плитки и рамку места на полной карте; считать строки и столбцы не нужно.

MakeCode при преобразовании текста в блоки может скрывать стандартную инициализацию false. На новых реальных Blockly-снимках начальный блок сохранён явно; служебная null-инициализация ещё не используемого места двери не показывается как учебный JavaScript-блок. Все прежние цепочки программы сохранены.

`scripts/check-maze-sequence.mjs` проверяет начальное и конечное состояние, ссылки, диапазоны подсветки, сохранение начальной памяти и единственных спрайтов, порядок рисунка ключа и создание функций до их вызова. Промежуточные TypeScript-состояния для изображений компилируются и преобразуются в настоящие блоки MakeCode. Уроки используют прежние финальные образцы; новые `r*.ts` / `r*.py` — только промежуточные состояния.

## Просмотр и обновление

Необязательное `visual.images` содержит `{src, caption, type?}`. Одна картинка показывается как прежде; несколько переключаются кнопками внутри шага. При смене шага просмотр начинается сначала. Используется прежний `BlocksImage` с увеличением, перемещением, подгонкой и полноэкранным режимом. Все изображения включены в пакет как офлайн-ресурсы.

Для последовательностей изображений нужен новый lesson player приложения 0.1.1. Материалы 1.0.6 имеют `minAppVersion: 0.1.1`, поэтому установленное приложение 0.1.0 не примет их. Новый player принимает прежние пакеты с одиночными изображениями. Формат пакета остаётся 1; SHA-256 и запрет перезаписи старых версий сохраняются. Установщик пользователь выпускает через существующий Desktop release.

Новые строки кода имеют зелёный фон и полосу, изменённые — оранжевые. Определение диапазонов, защита копирования, Electron 44.6.0, macOS naming-fix и упаковка сохранены.

Технические проверки: последовательность, JSON и ресурсы; одиночные и множественные изображения без браузера; валидация формата, совместимости и SHA-256; неизменность старых пакетов; `npm run build`. Внешний вид платформы, Electron и установщики не запускаются.
